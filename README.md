# 空き時間ビューア (Schedule Availability Viewer)

8月の30分刻みの予定データ（人×時間のスプレッドシート）を読み込み、粒度（1日／午前午後／1時間／30分）を切り替えながら「全員埋まり＝赤／一部埋まり＝黄／全員空き＝緑」で一覧できるツールです。30分単位で好きな時間ブロックを追加して、その枠だけの空き状況も確認できます。

ビルド不要の素のHTML/CSS/JSです。`index.html` を開くだけで動きます。

## 使い方

### 1. データを用意する（Googleスプレッドシート）

シートは以下のレイアウトを想定しています。

| datetime | 田中 | 鈴木 | 佐藤 |
|---|---|---|---|
| 2026-08-01 00:00 | 0 | 1 | 0 |
| 2026-08-01 00:30 | 0 | 1 | 0 |
| ... | | | |

- 1列目：日時（`YYYY-MM-DD HH:MM` 形式を推奨。`8/1 9:00` のような年省略形式にも対応、その場合は画面の「年」欄の値を使います）
- 2列目以降：人物名を列見出しにし、その30分枠に用事があれば `1`、なければ `0`（空白も0扱い）
- 日付列と時刻列を分けている場合（例：A列に日付、B列に時刻）も自動判定して読み込みます

既存シートが「行＝人、列＝日時」など違うレイアウトの場合は、`datetime, 人1, 人2, ...` の形に転置・整形してから使ってください。

### 2. シートをWebに公開してCSV URLを発行する

1. Googleスプレッドシートを開く
2. `ファイル` → `共有` → `ウェブに公開`
3. 公開する範囲を対象シートに設定し、形式を **「カンマ区切りの値(.csv)」** に変更
4. 発行されたURLをコピー

このURLは誰でも閲覧できる状態になります（読み取り専用）。非公開のまま使いたい場合は別方式（OAuth連携）への変更が必要です。

### 3. アプリで読み込む

1. `index.html` をブラウザで開く（ダブルクリックでOK。もしくは `npx serve .` などで配信）
2. 「公開スプレッドシートのCSV URL」欄にURLを貼り付け→「読み込む」
3. ブラウザのCORS制限で失敗する場合は、スプレッドシート側で該当範囲を選択してコピーし、「CSVを直接貼り付け」欄にペースト→「貼り付けた内容を読み込む」
   - スプレッドシートからのコピペはタブ区切りになりますが、そのまま貼り付ければ自動認識します
4. 動作確認したいだけなら「サンプルデータを試す」ボタンでダミーデータが読み込まれます

### 4. グリッドの見方

- **縦軸**：選んだ粒度での「日付×時間帯」の行（例：1時間ごとを選ぶと「8/1 09:00」「8/1 10:00」…と日付ごとにグループ化されて31日分並ぶ）
- **横軸**：人の名前の列
- 上部の「1日／午前午後／1時間ごと／30分ごと」ボタンで行の粒度を切り替え
- 各マスにマウスを乗せると「その人・その時間帯で何コマ中何コマ埋まっているか」が確認できます

### 5. カスタム時間ブロックを追加する

グリッド右上の「＋」ボタンを押すと入力バーが開きます。開始・終了時刻（30分単位）とラベル（任意）を指定して「全日付に追加」を押すと、その時間帯が金色のマーカー付きの行として各日付グループの末尾に追加されます。チップ横の「×」で削除できます。

## 色の判定ロジック

各マス（＝ある1人・ある時間帯）について、その時間帯を構成する30分コマの値を集計し、

- 全コマ `1` → 🔴 赤（その時間帯は完全に埋まっている）
- 全コマ `0` → 🟢 緑（その時間帯は完全に空いている）
- 一部だけ `1` → 🟡 黄（粒度を粗くした結果、埋まりコマと空きコマが混在）
- 該当するデータが1件もない → グレー（データなし）

30分ごと表示では1マス＝1コマなので黄色にはならず、赤か緑のみになります。粒度を粗くする（1時間・午前午後・1日）ほど、複数コマの混在によって黄色が現れやすくなります。
